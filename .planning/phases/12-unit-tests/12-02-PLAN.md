Создать `data_ingress/tests/test_recording_repository.py` с тестами (6 тестов).

Подход: RecordingRepository принимает AsyncSession через конструктор. Мокаем session как AsyncMock. Для методов использующих session.execute нужно настроить возвращаемый результат (result.scalars().all(), result.scalar_one()).

Фикстуры в файле:
- `mock_session` -- AsyncMock с настроенными session.get, session.add, session.flush, session.execute, session.delete
- `repo(mock_session)` -- RecordingRepository(mock_session)

Тесты:
1. `test_add_calls_session_add_and_flush` -- создать Recording(id=1, ts=100, file_url="url", user_id=1, status="uploaded"). Вызвать repo.add(recording). Проверить: session.add вызван с recording, session.flush awaited once.

2. `test_get_by_id_delegates_to_session_get` -- настроить session.get = AsyncMock(return_value=recording). Вызвать repo.get_by_id(1). Проверить session.get.assert_awaited_once_with(Recording, 1). Результат == recording.

3. `test_get_by_id_returns_none` -- session.get returns None. Проверить результат None.

4. `test_update_status_changes_status_and_flushes` -- session.get returns Recording(status="uploaded"). Вызвать repo.update_status(1, "transcribing"). Проверить recording.status == "transcribing", session.flush awaited.

5. `test_update_status_sets_error_message` -- session.get returns Recording(status="uploaded"). Вызвать repo.update_status(1, "failed", error_message="timeout"). Проверить recording.error_message == "timeout".

6. `test_get_page_returns_items_and_count` -- настроить session.execute для двух вызовов:
   Первый (count query) возвращает мок с scalar_one() = 42.
   Второй (items query) возвращает мок с scalars().all() = [recording1, recording2].
   Использовать side_effect на session.execute для разных результатов.
   Вызвать repo.get_page(offset=0, limit=20, user_id=1). Проверить результат == ([recording1, recording2], 42).

ВАЖНО: session.get -- это AsyncMock (await session.get(...)). session.add -- синхронный (MagicMock). session.flush -- AsyncMock. session.execute -- AsyncMock. Для session.execute возвращаемый объект (result) -- обычный MagicMock (не async), т.к. scalars().all() и scalar_one() -- синхронные методы.

from contextlib import asynccontextmanager

@pytest.fixture
def mock_session_and_factory():
    session = AsyncMock()

    @asynccontextmanager
    async def factory():
        yield session

    return session, factory

@pytest.fixture
def auth_service(mock_session_and_factory):
    _, factory = mock_session_and_factory
    return AuthService(factory, secret="test_secret", algorithm="HS256", expire_minutes=60)
